# Problem statement

## Client context

- **Delivery organisation:** Zynx Technologies Ltd
- **Domain client:** Financial Services Client
- **Engagement type:** Implementation Delivery

## Business problem

The Financial Services Client needed a governed medallion pipeline that curates investor and fund transaction history so investment teams can answer fund performance, peer comparison, MoM trend, and post-hoc adjustment questions without ad-hoc spreadsheet work.

## Success criteria (engagement)

- Clear architecture and ownership model
- Inspectable artefacts in Git (docs, diagrams, code/notebooks)
- Domain-safe documentation suitable for public portfolio audit
- Handover path for client engineering teams
